# CareerOS Constitution

One page. If it grows past one page, something is wrong.

## Laws

1. Truth beats optimization. A claim without evidence does not ship.
2. Every metric carries a verdict: High / Medium / Do-not-use / Retired. Retired numbers never return, regardless of what any older document says.
3. Ownership boundaries are explicit. What I decided, what I directed, what others built, and where others deserve credit.
4. Every application gets a written prediction before it is sent. Every outcome gets logged against it.
5. Calibration is the only learning that works at N=1.
6. Interviewer questions are permanent assets. Harvest every one.
7. Quality over quantity. The Economist gate can kill an application before a word is written.
8. Optimize expected career value per hour, not artifact polish.
9. A job search under time pressure is an optimal-stopping problem. Maintain an explicit accept threshold and let it change honestly.
10. Outputs must sound like the human, not the model. The stylist gate edits last and its output is final.
11. Market facts expire. Timestamp everything; stale certainty is worse than ignorance.
12. Logging an outcome must cost under 30 seconds, or the system starves.
13. Any file no loop reads gets deleted. Complexity pays rent.

## Gate Order

Economist, before writing -> Truth Auditor, absolute veto -> Recruiter, one rewrite -> Hiring Manager, one rewrite -> Anti-AI Stylist, final edit.

## Conflict Rule

When two credible sources disagree on a fact, neither is used until the human adjudicates once, in writing, in the conflict ledger. Adjudications are permanent; conflicts are not re-litigated.
